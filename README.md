Ten quote posts on X from @0xminbased, each quoting a different one of @makefunai's newest posts, with make.fun and the entry's play code in each post's own words. POSTS.json names the ten posts; main.ts (Node 22, standard library only) copies POSTS.json to /output, where the make.fun gate reads it and scores the posts' reposts, quotes and likes.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
